## 2026.04.02 重新思考PRD和SPEC

综合当前项目里的各种 md 资料，以及你的了解和思考。重新整理一份 PRD 和 SPEC 文档，并在PRD预留标记还需要哪些文档才能完整性的实现产品。

重申产品目标：
我希望这个产品是一个个人或小团队的助手，基于 AI agent 的智能体系统，能够处理复杂的任务和决策，支持团队协作和任务分配，能够自动处理任务，跟踪任务进度，审核任务结果，与外部系统集成。
- 架构核心简单稳定，围绕核心实现后续功能扩展。
- 能长期性的执行任务，减少人为干预，提高效率。
- 可观测，可追踪任务执行过程，能够及时发现和解决问题。
- 自我学习进化 能够根据任务执行结果和团队反馈，不断优化任务处理流程和决策策略
- 可扩展 接口/协议优先，不固化特定的实现或工具，能够根据需求添加新的功能模块或替换工具实现
- 与外部Agent对接 可以通过A2A协议，指挥 claude-code, codex 等工具实现功能，并可以持续跟进协作
- 使用简单 内置场景/工具能力，不需要复杂的配置或学习曲线，能够快速上手并开始使用
- 可以通过 CLI/WEB/IM/Channel 等方式与用户进行交互，支持文本、图片、视频等多种格式

## 2026.04.03 先思考规划帮我实现一个最小但是可扩展的 agent core loop

先思考规划帮我实现一个最小但是可扩展的 agent core loop，直接开始 v1 的产品功能太大了，外界的发展变化也很迅速。

- 它是任何一个 agent 启动运行的必须核心
- 通过接口、Hooks 方式提供任意的扩展能力
  - 通过 llm provider inteface 连接使用各家LLM
  - hooks 可拦截，修改执行中的关键节点
  - 通过 storage interface 提供存储 默认内置使用 files
  - more: prompt, context eng, tool interface
- 它是可以独立的包，可以嵌入到任何地方使用

see docs/superpowers/specs/2026-04-02-agentcore-design.md
